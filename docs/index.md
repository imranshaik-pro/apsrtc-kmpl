# APSRTC Report Automation

APSRTC Report Automation is a private operational reporting utility maintained for personal use.

The application automates preparation and storage of operational reports using data supplied by the authorized user. Google services are used only to create, update, and store the user's reporting files in the user's own Google account.

## Purpose

The application is used to:

- Generate APSRTC operational reports.
- Create and update Google Sheets used for reporting.
- Store generated report files in Google Drive.
- Run scheduled reporting workflows from GitHub Actions.

## Access

This application is intended only for the authorized owner/operator of the automation. It is not offered as a public service and does not sell or distribute user data.

## Contact

For questions about this application or Google account authorization, contact the developer through the support email configured on the application's Google OAuth consent screen.
